# Cat Food Center - robots.txt

# Fully open, deliberately. Search engines, AI assistants and answer engines
# are explicitly permitted to crawl, index, quote, summarise and cite this
# site; see LICENSE.md section 4. That permission is the point, not an
# oversight, so a future tightening of this file should be a decision somebody
# makes rather than something that happens by default.
#
# LICENSE.md is authoritative if this file and it ever appear to disagree.
#
# SCOPE, which matters here: this site is served from a subpath of
# azqato.github.io, a domain this project does not own. The robots.txt that
# actually governs crawler behaviour for that host is the one at
# https://azqato.github.io/robots.txt, which belongs to the domain owner. This
# file is served at https://azqato.github.io/catfoodcenter/robots.txt and is
# NOT the authoritative robots policy for the host. It is committed because it
# is correct if the site ever moves to its own domain, and because it records
# the intent either way. The same limitation applies to the sitemap below.

# One page asks not to be listed, and it asks in its own head rather than
# here: tools/tests.html carries <meta name="robots" content="noindex, follow">.
# It moved there from the repository root in M19, under the root policy in
# docs/PRD.md section 16.4; the noindex travelled with it, which is the
# advantage of a rule the page carries itself over one written down here.
# A Disallow line would have been the wrong instrument. It stops the fetch
# rather than the listing, and a URL disallowed from crawling can still be
# indexed from a link alone, with no description because nobody was allowed
# to read it. noindex says what is actually meant, and it only works because
# this file lets the crawler in to see it. See PRD open question 10.
